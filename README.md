# Star-Classification


This project focuses on building a Machine Learning model capable of classifying stars into different categories based on their physical characteristics. Using features such as temperature, luminosity, radius, magnitude, and color, the model predicts the most likely star type (e.g., Red Dwarf, White Dwarf, Main Sequence, Supergiant, Hypergiant).

The dataset undergoes preprocessing, normalization, and exploratory data analysis to understand correlations between stellar properties. Multiple classification algorithms were tested, and the best-performing model was selected based on accuracy and evaluation metrics.

To make the system accessible and interactive, the project includes a Streamlit web application. Users can input stellar parameters through sliders and dropdown menus, and the app instantly generates the predicted star category. The interface is simple, responsive, and ideal for demonstrations or educational use.
